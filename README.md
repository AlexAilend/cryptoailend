# CryptoAilend 1.1

Інтерактивна лабораторія прикладної криптології. Хейленко Олексій Олександрович, варіант 29.

## Запуск

Відкрийте `index.html` у сучасному браузері. Інтернет, сервер і встановлення пакетів не потрібні. Чотири алгоритми доступні в одному інтерфейсі. Для автоматичного копіювання потрібен HTTPS або localhost; локально результат можна виділити вручну.

## Де що лежить

| Файл | Призначення |
|---|---|
| `index.html` | Поля, кнопки, довідка й діалог перевірок |
| `style.css` | Оформлення, мобільна версія та друк |
| `js/config.js` | Абетка, ПІБ, початкові параметри варіанта |
| `js/validation.js` | Перевірка введених значень |
| `js/algorithms/caesar.js` | Шифр Цезаря |
| `js/algorithms/vigenere.js` | Віженер ROT2 |
| `js/algorithms/polybius.js` | Квадрат Полібія |
| `js/algorithms/rsa.js` | Ключі RSA, піднесення до степеня та блоки |
| `js/checks.js` | Контрольні приклади для кнопки перевірки |
| `js/ui/visuals.js` | Абетки, квадрати, підсвічування та таблиця кроків |
| `js/ui/export.js` | TXT, RSA-пакети JSON, перевірка імпортованих пакетів |
| `js/ui/app.js` | Стан інтерфейсу, обчислення та обробники кнопок |
| `tests.cjs` | Додаткові перевірки через Node |

Файли підключено звичайними script-тегами, щоб працював запуск подвійним натисканням на index.html. Вони додають свої функції до одного об’єкта `CryptoAilend`; збирача та системи залежностей немає. Порядок підключення видно наприкінці index.html. Коментарів майже немає: призначення визначають назви функцій і змінних.

## Найчастіші зміни

- Інше ПІБ, ключ, варіант: `config.js`.
- Інша формула алгоритму: його файл у `algorithms/`.
- Інші повідомлення про неправильне введення: `validation.js` або перевірки відповідного алгоритму.
- Інші кнопки чи підписи: `index.html`; поведінка — `ui/app.js`.
- Інші кольори: змінні на початку `style.css`.

## Робота з програмою

1. Виберіть алгоритм, введіть дані та натисніть «Виконати».
2. Виберіть крок стрілками або кнопкою літери. «Пояснити цей крок» показує пояснення звичайними словами.
3. «Взяти результат як вхід» переносить результат і перемикає напрям перетворення.
4. Для RSA ця кнопка також зберігає довжини блоків у поточному сеансі.
5. «RSA-пакет JSON» зберігає шифротекст, N та довжини. У новому сеансі введіть відповідні p, q, d і відкрийте пакет. Закритого ключа в пакеті немає.
6. «Перевірка алгоритмів» показує 14 відтворюваних прикладів із очікуваними та фактичними відповідями.
7. Експорт TXT містить введені дані, параметри, результат та протокол; якщо параметри чи поля змінено, спочатку повторно натисніть «Виконати».

## Математичні правила

Українська абетка з 33 літер, індекси 0…32. Цезар: k=3. Віженер ROT2: T[r,c]=A[(r+c+2) mod 33], ключ КРИПТО; пробіли ключ не просувають. Полібій: квадрат 6×6 по рядках, координата — рядок і стовпець від 1, `/` позначає пробіл. Зсув Цезаря, ключ та точне трактування ROT2 — явно обрані параметри, оскільки умова не деталізує їх.

RSA: p=154799, q=1093, d=22305175; N=169195307; φ=169039416; e=150241471. M=2897878135 розбивається на 28978781 | 35, шифротекст 124031897 | 66937552. Задане C=20979746 розшифровується у 863804.

Для M≥N ширина блока дорівнює len(N)−1. Для коротшого M зберігається один блок. Довжини блоків зберігають початкові нулі. Без метаданих ручне RSA-розшифрування повертає окремі числові блоки; об’єднувати їх із припущенням про початкові нулі програма не буде. Для такого результату кнопка перенесення назад просить вибрати блок або імпортувати пакет.

## Перевірка розробником

Запустіть із кореня проєкту:

```bash
node tests.cjs
```

Додатково перевіряються всі 33 зсуви Цезаря, RSA на граничних значеннях, числа кратні p/q, імпорт пакетів та збереження нулів у повідомленні `123456780001`.

## GitHub Pages

Завантажте весь вміст `dist/` у корінь нового репозиторію. Папку `js/` та її підпапки слід зберегти. Не завантажуйте лише index.html: потрібні всі сусідні файли. Для публікації виберіть гілку main і кореневу папку в налаштуваннях Pages. Якщо зберігаєте повну структуру репозиторію, налаштуйте публікацію `dist/` через Actions. Службова папка `.openai` для GitHub Pages не потрібна.

## Обмеження

Навчальна реалізація без RSA padding; не призначена для реального захисту даних. Немає зовнішніх пакетів, API, аналітики та передачі введених даних. p,q≤10 000 000; текст до 5000 символів; кнопки вибору кроків — перші 400, решта доступна стрілками. Для локального відкриття потрібен браузер із підтримкою BigInt.
