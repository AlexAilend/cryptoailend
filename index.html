Математика без чорної скриньки

Нумерація української абетки: від 0 до 32, з Ґ, Є, І та Ї. Класичні шифри переводять текст у верхній регістр.

Цезар

c = (x + k) mod 33. При розшифруванні зсув віднімається. Типове k = 3 — обраний параметр, не вимога викладача.

Віженер ROT2

Визначення цієї реалізації: T[r,c] = A[(r + c + 2) mod 33]. Рядок задає літера ключа, стовпець — літера тексту. Ключ КРИПТО обрано для демонстрації, в умові ключ не заданий.

Полібій

Квадрат 6 × 6 заповнюється українською абеткою по рядках; останні три клітинки порожні. Координата: рядок, потім стовпець. / позначає пробіл.

RSA

N = pq; φ(N) = (p−1)(q−1); ed ≡ 1 mod φ(N). C = Mᵉ mod N; M = Cᵈ mod N. Використано точну арифметику BigInt.

Блоки M: ширина len(N)−1; для варіанта 29 це 8 цифр: 28978781 | 35. У програмі зберігаються довжини для зворотної перевірки. При ручному розшифруванні кожен блок виводиться окремо: довжину початкових блоків треба знати для відновлення початкових нулів.

Це навчальний RSA без padding. Сталі малі ключі та класичні шифри непридатні для реального захисту даних.

Кнопка «Взяти результат як вхід» перемикає напрям і зберігає довжини RSA-блоків. Експорт RSA-пакета JSON зберігає шифротекст, модуль N та довжини. Пакет можна відкрити в новому сеансі після введення відповідного закритого ключа.
